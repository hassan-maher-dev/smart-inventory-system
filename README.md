# Smart Inventory Management System

## Project Overview
This project aims to develop a real-time inventory tracking system that generates alerts for low stock and produces management reports. The focus is on implementing DevOps practices, including automation, containerization, and scalable infrastructure.

## Key Deliverables
* **Microservices**: Dockerized Inventory and Alert services.
* **Orchestration**: Kubernetes deployment for scalability.
* **CI/CD**: Automated pipelines using Jenkins.
* **Infrastructure**: AWS resources provisioned via Terraform.
* **Configuration**: Server setup and service configuration using Ansible.
* **Monitoring**: Real-time system metrics using Prometheus and Grafana.

## Tech Stack
* **Cloud**: AWS (EC2, S3, VPC).
* **DevOps**: Docker, Kubernetes, Jenkins, Terraform, Ansible.
* **Monitoring**: Prometheus, Grafana.
* **Proxy**: Nginx.
